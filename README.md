# 🧾 CCD（Code-Copyright-Docgen）
一个用于生成软著源代码文档（DOCX）的工具

## ✨ 简介
CCD 会扫描源码目录，将代码按文件组织并排版输出为 DOCX，满足软著材料中"源代码文档"的常见格式需求。支持命令行与图形界面，支持多目录/多后缀、排除路径、过滤空行与注释、以及使用 DOCX 模板统一样式。

## ✅ 特性
- **多目录扫描**：可指定多个源码目录
- **多语言后缀**：按后缀识别语言并过滤注释（如 py/js/ts/go/java/c/cpp 等）
- **过滤规则**：默认过滤空行与注释行，也可选择保留
- **排除路径**：支持排除文件/目录；GUI 支持读取 .gitignore（可解析的静态路径）
- **文档排版**：页眉标题、字体、字号、段前/段后/行距可配置
- **模板支持**：可传入 DOCX 模板统一样式
- **文件选择**：支持从扫描结果中多选文件生成文档（GUI）
- **代码统计**：统计代码总行数（过滤后）
- **60页模式**：支持生成前30页+后30页，适用于≥3000行代码的项目
- **等宽字体**：支持 Consolas、Courier New 等等宽字体
- **页码功能**：支持自定义页码格式，默认"第 x 页 共 x 页"
- **独立页眉字体**：页眉标题可单独设置字体和字号

## 📋 页面规格
软著文档的标准格式要求：
- **纸张大小**：A4 (297mm × 210mm)
- **页边距**：上下左右各 2.5cm
- **字体**：等宽字体（如 Consolas、Courier New）或宋体
- **字号**：小五号或五号
- **行间距**：单倍行距
- **每页行数**：不少于 50 行（最后一页除外）
- **总页数要求**：
  - ≥3000 行：提交 60 页（前30页+后30页）
  - <3000 行：提交全部
- **页眉**：软件全称+版本号
- **页脚**：页码
- **编码**：UTF-8（避免乱码）

## 🧩 使用

### 命令行模式
```bash
python cli.py --help
python cli.py -i ./src -o ./code.docx
```

常用示例：
```bash
# 多目录 + 多后缀
python cli.py -i ./src -i ./tests -e py -e js -e ts -o ./code.docx

# 保留空行/注释（默认会过滤空行与注释）
python cli.py -i ./src -o ./code.docx --keep-blank-lines --keep-comment-lines

# 排除路径（可重复指定）
python cli.py -i ./src --exclude ./src/vendor --exclude ./src/generated -o ./code.docx
```

### 图形界面
```bash
python cli.py --gui
```

#### 图形界面新功能说明

1. **文件选择与预览** ⭐新增
   - 先点击"扫描文件数"获取所有符合条件的文件
   - 点击"选择文件"打开文件多选对话框
   - **左右两栏布局**：左侧显示可选文件，右侧显示已选文件
   - **多选操作**：支持 Ctrl+点击多选，Shift+点击范围选择
   - **添加/移除**：通过中间按钮或双击文件进行添加/移除
   - **顺序调整**：右侧已选文件支持置顶、上移、下移、置底
   - **文件预览**：点击任意文件名，底部预览面板自动显示文件内容
   - **预览设置**：可选择预览行数（20/50/100/200行）
   - **文件信息**：显示文件名、大小、总行数、编程语言
   - **搜索过滤**：实时搜索文件名快速定位
   - 全选/清空快捷操作

2. **统计代码行数**
   - 点击"统计代码行数"查看过滤后的总行数
   - 如果选择了特定文件，只统计选中文件的行数
   - 统计结果会显示在"运行概览"区域

3. **60页模式**
   - 勾选"启用60页模式（前30+后30）"
   - 适用于代码行数≥3000行的项目
   - 自动提取前30页（1500行）和后30页（1500行）
   - <3000行时建议不启用，直接生成全部

4. **等宽字体**
   - 正文字体下拉框中包含 Consolas 和 Courier New
   - 推荐使用等宽字体以提高代码可读性

5. **页眉字体设置**
   - 独立设置页眉的字体和字号
   - 默认为宋体 10.5号
   - 可与正文字体不同

6. **页码格式自定义**
   - 预设格式：
     - `第 {page} 页 共 {total} 页`
     - `{page} / {total}`
     - `Page {page} of {total}`
     - `{page}`（仅显示页码）
   - 选择"自定义..."可输入自己的格式
   - 使用 `{page}` 表示当前页，`{total}` 表示总页数

7. **错误日志记录** ⭐新增
   - 自动记录所有操作和错误信息
   - 点击"查看日志"按钮查看详细日志
   - 支持查看全部日志和错误日志
   - 可以清空日志或打开日志目录
   - 日志文件位置:
     - Windows: `%LOCALAPPDATA%\CCD\logs\`
     - Linux/Mac: `~/.ccd/logs/`
   - 自动轮转,最大10MB,保留5个备份文件

## 📝 使用建议
- **后缀选择**：仅勾选/传入需要纳入文档的语言后缀，避免把构建产物或依赖代码写入软著材料
- **排除规则**：优先通过 `--exclude` 精确排除 `vendor/`、`dist/`、`build/`、`node_modules/` 等目录
- **样式统一**：如有固定格式要求，准备一份 DOCX 模板并在生成时传入以统一字体与段落样式
- **代码统计**：在生成前先统计行数，确定是否需要启用60页模式
- **文件筛选**：对于大型项目，建议先扫描，然后选择核心文件生成文档

## 🎯 典型工作流程

1. **添加源码目录**：点击"添加目录"选择项目根目录
2. **选择文件后缀**：点击"选择"按钮，勾选需要的编程语言后缀
3. **排除无关目录**：添加 node_modules、dist、build 等目录到排除列表
4. **扫描文件**：点击"扫描文件数"查看有多少文件符合条件
5. **统计行数**：点击"统计代码行数"查看过滤后的总行数
6. **筛选文件**（可选）：如需精确控制，点击"选择文件"手动筛选
7. **配置格式**：
   - 设置页眉标题（软件名称+版本号）
   - 选择等宽字体（推荐 Consolas）
   - 如果≥3000行，勾选"60页模式"
8. **生成文档**：点击"生成文档"，等待完成
9. **打开目录**：点击"打开输出目录"查看生成的文档
